# 🌦️ Weather Dashboard

A responsive weather application built using **React.js** and **Material UI** that displays real-time weather information for cities around the world.

## ✨ Features
- Search weather by city name.
- Display current temperature, humidity, and weather conditions.
- Show minimum, maximum, and feels-like temperatures.
- Dynamic weather images and icons.
- Responsive user interface.

## 🛠️ Technologies
- React.js
- JavaScript
- Material UI
- CSS3
- OpenWeather API
- Vite

## ⚙️ Installation

```bash
git clone YOUR_REPOSITORY_URL
cd weather-widget
npm install
npm run dev
```

Create a `.env` file in the root directory and add your OpenWeather API key:

```env
VITE_API_URL=https://api.openweathermap.org/data/2.5/weather
VITE_API_KEY=YOUR_API_KEY
```
